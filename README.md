# dpReader31 — Web Flash và firmware

Kho này phục vụ [Web Flash](https://dephia31.github.io/dpReader31/), OTA và
[tải các bản firmware đã phát hành](https://github.com/dephia31/dpReader31/releases)
cho Metalio E-Ink4 Plus S31.

- `web/` chứa giao diện Web Flash.
- `releases/` chứa firmware, manifest OTA và mã kiểm tra cho Full và Love Book.
- `metalio-s31-update.json` giữ đường dẫn manifest Full tại gốc website.

Quy trình Pages kiểm tra các gói phát hành trước khi triển khai.
