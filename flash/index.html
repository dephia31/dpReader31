刷新，也有选择

记住你的阅读日常

阅读进度、时长、个性签名与资料卡。自动休眠、配置备份，让使用更省心。

BEFORE YOU START

你可能想知道。

网页刷机和 Bin 升级，该选哪一个？

第一次安装，或设备还没有兼容的双分区基础包时，使用网页刷机。已安装 rc72 及以上兼容基础包，可以通过 TF 卡升级应用；联网 OTA 还需要支持 OTA 的基础版本。具体以使用说明及当前固件提示为准。

连接后找不到墨水屏，怎么办？

确认使用可传数据的 USB 线，在电脑的 Chrome 或 Edge 打开页面。关闭占用串口的其他程序；在墨水屏「设置 → 升级和恢复 → BOOT 刷机」进入 BOOT 模式，再连接安装。更多步骤见使用说明。

刷完之后，书籍和字体从哪里来？

固件不附带书籍与额外字体。将有权使用的 EPUB、TXT 和字体文件放入 TF 卡，或通过 WiFi、热点、USB 传输。推荐书籍放 books 文件夹，字体放 fonts 文件夹。

保存配置，会一起保存书籍文件吗？

配置备份保存设置和阅读数据，包括进度、阅读时长、书签、收藏、资料卡、签名与网络设置。书籍、字体、头像和壁纸等文件仍需单独保留在 TF 卡上。
