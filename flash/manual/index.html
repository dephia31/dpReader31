第 01 章 / 5 项操作

认识设备与四个主页面

先认识入口，再开始操作。屏幕下方的三枚触控键和屏幕里的底栏，是两组不同的控制。

01.01切换首页、书架、文件管理和设置

操作路径任意主页面 → 底部导航栏
  1. 查看屏幕最下方的四个图标：从左到右依次为「首页」「书架」「文件管理」「设置」。
  2. 轻点图标或它下方的名称。当前位置由图标上方的小横条表示。
  3. 在二级页面，优先用左上角的圆形返回键回到上一层；底栏仍出现时，也可以直接切换主页面。
  4. 正在输入文字时，屏幕底部会出现键盘。先完成或取消这次编辑，再回到主页面。

完成之后每个入口都有自己的用途：继续阅读、找书、管理卡内文件、调整设备。

操作提醒阅读全屏会隐藏部分界面；这时用已配置的按键呼出阅读工具栏。

01.02分清三枚触控键与屏幕底栏

操作路径屏幕下方：— ○ —
  1. 左侧短横线是左键，中间圆圈是中键，右侧短横线是右键。它们不是底栏中的书架或设置图标。
  2. 「短按」指轻点后松开；「长按」指保持约半秒后再松开。
  3. 默认阅读时：左键上一页，中键阅读工具栏，右键下一页，中键长按返回主页。底部上滑始终可呼出工具栏。
  4. 阅读按键可以自定义。本文写「默认」时，指没有修改过按键控制的情况。

完成之后通过同一组按键，既能翻页，也能按自己的习惯安排工具栏和全屏。

操作提醒阅读设置中的按键控制，只定义阅读操作；不要把其他页面的返回行为当成阅读按键设置。

01.03读懂顶部状态栏

操作路径屏幕顶部
  1. 左侧显示时间；中间显示你设置的状态栏签名，留空时不显示签名。
  2. 右侧的 WiFi / 蓝牙标志表示对应功能状态；电量百分比和电池图标显示当前电量。
  3. 时间不正确时，到「设置 → 阅读与设备 → 日期与时间」进行对时或手动设置。
  4. 从顶部边缘向下滑，可以打开四个圆形快捷按钮。

完成之后查看状态不必进入设置。

操作提醒没有 WiFi 图标时，先确认是否已连接，而不仅是曾经保存了密码。电量是软件估计值，不是精密测量读数。

01.04使用下拉快捷面板

操作路径从屏幕顶部边缘向下滑
  1. 手指从状态栏上边缘向下滑，展开带框线的快捷面板。
  2. 四个圆形按钮从左到右为：WiFi、蓝牙、手动全刷、锁屏。
  3. 点 WiFi：尝试连接最近保存的网络；连接后再次点可断开。它不是打开 WiFi 设置的按钮。
  4. 点蓝牙：开启或关闭蓝牙翻页器功能；首次配对仍要到系统设置进行。
  5. 点全刷：清理当前画面残影。点锁屏：进入选定的锁屏样式。
  6. 向上滑、轻点面板外部，或使用返回操作，可以收起面板。

完成之后快捷按钮用来直接执行动作。

操作提醒传输或更新正在进行时，网络操作可能受保护；先完成或取消任务，再切换无线功能。

01.05锁屏、唤醒与电源选项

操作路径设备电源键
  1. 正常使用时短按电源键，进入锁屏。若阅读中启用了「电源键翻页」，短按改为下一页，长按用于锁屏。
  2. 唤醒后若设置了锁屏密码，输入四位数字；没有密码时，返回锁屏前的使用状态。
  3. 在未启用阅读电源键翻页的常规页面，长按电源键会显示「电源选项」，可选「重启」或「关机」。
  4. 「关机」的具体行为由「设置 → 阅读与设备 → 关机睡眠」决定：彻底关机，或先浅睡再深睡。

完成之后锁屏保留画面；彻底关机则需要重新开机。

操作提醒墨水屏断电后仍可能保留图像。不要仅凭屏幕有画面判断设备仍在运行。

第 02 章 / 5 项操作

第一次安装与开机

电脑网页刷机用于首次安装与修复；已经正常使用的设备也可以通过 TF 卡或联网升级。

02.01准备刷机所需物品

操作路径电脑浏览器 → https://kiikoread.com/
  1. 确认设备为适配型号 RDP-G01-W。不要把本项目固件刷到其他型号。
  2. 准备一根可传数据的 USB 线，接到电脑的稳定 USB 接口。能充电不代表这根线能传数据。
  3. 在电脑端 Chrome 或 Edge 打开官网，进入「刷机与下载」。浏览器需要支持串口连接。
  4. 关闭其他占用同一设备串口的刷机网页、日志工具或终端。
  5. 如设备还有正常系统，建议先保存当前配置，并复制备份文件到电脑。

完成之后具备连接浏览器安装器的条件。

操作提醒手机里的微信内置浏览器、Safari 和普通手机浏览器不作为本文的网页刷机操作环境。

02.02通过官网安装固件

操作路径官网 → 刷机与下载 → 选择版本 → 连接
  1. 先在官网选择要刷入的版本；核对版本号、发布时间和更新日志。
  2. 用 USB 连接墨水屏，点击网页连接或安装入口。
  3. 在浏览器弹出的串口列表中，选中对应设备，再点击连接。若列表有多个设备，可根据插拔后新增的条目辨认。
  4. 进入安装弹窗，按提示选择安装。正常保留数据的操作不要选择「擦除设备」。
  5. 保持线材连接，等写入完成、校验完成和设备重启；不要中途拔线或切断供电。
  6. 开机后进入「系统升级」页面核对当前版本，再检查书架和个人设置。

完成之后完成全量安装，应用程序、引导与分区布局按该版本配套。

操作提醒全量网页刷机和 TF 升级 Bin 不是同一种包；网页清单会安排地址，不要把应用 Bin 当作完整镜像写到地址 0。

02.03安装器无法初始化时进入 BOOT 模式

操作路径设置 → 升级和恢复 → BOOT 刷机
  1. 保持设备能进入正常系统，并用 USB 连接电脑。
  2. 打开系统设置，向下滑到「升级和恢复」，点「BOOT 刷机」。
  3. 在「电脑刷机」页面点击「进入 BOOT 模式」。设备会切到下载状态，电脑可能重新识别串口。
  4. 回到官网安装器，重新选设备串口，按安装步骤操作。
  5. 刷完后等待设备启动；BOOT 模式本身不会显示普通阅读界面。

完成之后设备进入适合完整刷写的下载模式。

操作提醒这款设备没有可供本文指引的实体 BOOT / RESET 按钮。不要照其他开发板的“按住 BOOT”教程寻找不存在的按键。

02.04选择当前版、历史版与 Bin

操作路径官网 → 刷机与下载 → 版本选择
  1. 展开版本选择，选择当前正式版或网页仍提供的历史正式版。
  2. 核对显示的版本、时间和更新日志已随选择变化。
  3. 需要电脑刷机时，使用当前选择对应的网页安装入口。
  4. 需要 TF 卡升级时，下载对应版本的应用 Bin，并按 TF 升级章节保存到卡根目录。
  5. 需要离线转发时，可到项目 GitHub Releases 下载对应版本附件，再连同版本说明发给对方。

完成之后选择哪个版本，就使用哪个版本配套的下载与安装说明。

操作提醒官网另列的 rc88 固定下载属于指定历史版本；不要将它误认为当前最新版本的 Bin。

02.05第一次开机后开始阅读

操作路径准备 TF 卡 → 文件管理 → 书架
  1. 准备 FAT16 / FAT32 格式的 TF 卡；先把书籍放进 books 文件夹。没有文件夹时可在电脑上创建。
  2. 插入 TF 卡后打开「文件管理」，确认可看到存储状态和卡内目录。
  3. 切到「书架」，等待扫描；需要时点「管理 → 重新扫描」。
  4. 点一本书打开。首次打开或大书解析可能比回到已读位置慢，避免反复点击。
  5. 按中键呼出工具栏，进入字体设置调整阅读字号。

完成之后看到正文，即可开始使用触摸或按键翻页。

操作提醒固件不附带个人书籍。书架为空时，先检查文件是否已导入，而不是再次刷机。

第 03 章 / 5 项操作

TF 卡与文件存放

书籍、字体和图片放在卡上；设备配置、阅读记录和卡内文件是不同的东西。

03.01确认 TF 卡格式和兼容性

操作路径电脑磁盘信息 / 文件管理
  1. 在电脑上查看卡的文件系统，确认是 FAT16 或 FAT32。当前固件没有启用 exFAT。
  2. 先确认电脑能够正常读取、写入和再次打开卡内文件。
  3. 容量不是唯一条件。即使同为 FAT32，不同卡的初始化、分区和供电表现也可能不同。
  4. 将卡插入设备，进入文件管理查看存储卡状态。读取异常时记录完整提示。
  5. 如果需要重新格式化，先把所有书籍、字体、图片和备份复制到电脑；格式化不是无损操作。

完成之后获得可供设备挂载的卡和可追踪的错误信息。

操作提醒不要把 256GB 一概当作不能用，也不要仅凭 FAT32 一概认定所有卡都已验证兼容。

03.02卡片提示需要格式化时，如何处理

操作路径文件管理 → 存储卡卡片 → 需要格式化
  1. 先把卡连接电脑，复制仍要保留的书籍、字体、图片和备份。
  2. 设备检测到卡在槽内，但文件系统无法挂载，且具备格式化条件时，存储卡卡片会显示「需要格式化」。普通未插卡或通信超时不一定出现此入口。
  3. 确实需要清空这张卡时，轻点存储卡卡片一次，查看「将清空卡内全部数据，再点确认」提示。
  4. 决定保留数据时不要再次点；需要清空并继续时，再点卡片确认格式化。
  5. 等待结果，不拔卡、不关机。成功后重新导入文件；失败时记录完整错误提示，先在电脑上检查卡。

完成之后格式化会重建卡上的文件系统，并清空原有内容。

操作提醒此操作无法通过普通配置备份恢复书籍和图片。不能用“重新扫描”替代修复损坏的文件系统。

03.03用电脑整理卡内文件

操作路径电脑 → TF 卡根目录
  1. 把 EPUB 或 TXT 文件放入 books，保留原扩展名。不要只复制解压后的 EPUB 文件夹。
  2. 把 TTF 字体放入 fonts，图片放入 pictures。文件夹可用小写英文，便于与本文路径对照。
  3. 把系统升级包和配置备份放到根目录，不要再套一层文件夹。
  4. 复制完成后安全弹出卡或 USB 磁盘，再回到设备读取。

完成之后卡内资源按功能分类，后续操作更容易找到。

操作提醒Mac 复制产生的 ._ 开头附属文件不是书籍或字体；不要选这些文件使用。

03.04让书架扫描自己指定的书籍目录

操作路径文件管理 → TF 卡目录 → 目标文件夹
  1. 打开文件管理中的目录，逐层进入存放书籍的文件夹。
  2. 在该文件夹页面找到「设为书籍目录」，点击它。
  3. 返回书架，等待目录更新；如内容未变化，进入「管理 → 重新扫描」。
  4. 确认目标文件夹中的 EPUB / TXT 已出现，再开始阅读。

完成之后自定义书籍目录参与书架读取。

操作提醒仅改变扫描位置不会移动文件。移出书架的书籍仍需主动重新打开，才能重新上架。

03.05使用自己的字体文件夹

操作路径文件管理 → TF 卡目录 → 目标文件夹 → 设为字体目录
  1. 将需要使用的 TTF 文件放到同一个目标目录。
  2. 在设备文件管理中进入这个目录，点「设为字体目录」。
  3. 回到系统字体或阅读字体选择页，查看新的字体列表。
  4. 如没有出现，先确认文件是实际 TTF 字体、不是压缩包、不是 ._ 附属文件。

完成之后字体目录变化后可在选择页使用。

操作提醒rc90 字体扫描按 .ttf 扩展名识别。传输页虽允许上传 OTF，但不要据此认定设备一定可选择 OTF；本文使用 TTF 操作。

第 04 章 / 2 项操作

首页与继续阅读

首页把最近阅读和阅读记录放在一起。

04.01回到上一次阅读位置

操作路径首页 → 继续阅读
  1. 点底栏「首页」，找到「继续阅读」模块。
  2. 核对封面和书名，点击该模块进入书籍。
  3. 设备根据保存的阅读位置恢复正文；书籍仍需存在于原来的文件路径。
  4. 若最近一本书曾被异常打开中断，先处理启动恢复提示，再决定是否重新打开。

完成之后继续已保存的阅读，不必从书架重新找书。

操作提醒移动或重命名卡内文件可能改变进度关联路径；恢复记录时尤其要保留原目录。

04.02查看首页的阅读记录

操作路径首页 → 阅读记录区
  1. 查看首页阅读时长或天数条形图，了解近期是否读过书。
  2. 阅读状态会随正常翻页、离开阅读和锁屏保存。
  3. 要查看单本书详情，打开这本书，再点「阅读工具栏 → 阅读统计」。

完成之后首页适合看近期概况，阅读统计适合看当前书。

操作提醒日期不正确会影响按天理解记录，先在日期与时间里校准。

第 05 章 / 11 项操作

书架：排序、搜索与管理

先讲最常用的找书，再讲批量整理。收藏、最近排序和移出书架有不同的含义。

05.01切换三种书架外观

操作路径设置 → 显示 → 书架样式
  1. 打开设置，向下滑到「显示」，点击「书架样式」。
  2. 在「深色书轨」「亚克力书架」「列表书架」中点选一种。已选项会显示选中标记。
  3. 点底栏书架，查看实际效果。深色书轨与亚克力每页 9 本，列表每页 4 本。
  4. 列表可同时看到封面、书名、作者、已读比例和进度条；封面统一尺寸，细长封面会等比放大后裁切。

完成之后换样式不改变书籍文件和阅读位置。

操作提醒快刷会改变封面与亚克力的渲染方式，但不是第四种书架样式。

05.02按照最近阅读排列书架

操作路径书架 → 右上角「管理」 → 顶部中间排序按钮
  1. 进入书架，点右上角「管理」。
  2. 在管理书架页面顶部找到三个按钮：来源、排序、搜索。排序是中间那个。
  3. 如果中间显示「按名称」，点一次，让文字变成「按最近」。若已显示「按最近」，无需再点。
  4. 点页面底部中间的「完成」，返回书架。
  5. 最近阅读过的书会优先排列；收藏的书仍放在非收藏书之前。再次进入管理点「按最近」，可切回「按名称」。

完成之后排序选择会保存，不需要每次开机重设。

操作提醒这里的“最近”指阅读记录中的最近打开时间，不是 TF 卡中文件的复制时间。切换排序会清除当前批量勾选；先排序，再选择要处理的书。

05.03切换书架上一页和下一页

操作路径书架 → 底部书籍数量两侧的箭头
  1. 查看书架底部的「本数 · 当前页 / 总页」提示。
  2. 点左侧 ‹ 返回上一页，点右侧 › 前往下一页。第一页或最后一页的不可用箭头会弱化。
  3. 支持横向滑动切换书架页；使用蓝牙翻页器时，也可以用对应方向或已学习的上一页 / 下一页。
  4. 在管理页面，使用底部「上一页」「下一页」，不要点「完成」来翻页。

完成之后书籍数量和分页以当前筛选结果及样式为准。

操作提醒9 本一页和 4 本一页的总页数不同，换列表样式后页数增加是正常的。

05.04按书名、拼音或首字母找书

操作路径书架 → 管理 → 搜索
  1. 进入「管理」，点顶部右侧「搜索」。
  2. 输入书名的一部分，也可以尝试拼音、拼音首字母或英文关键词。
  3. 中文拼音输入时先点候选词，确认文字已经进入输入框，再点搜索页的确认操作。
  4. 回到管理页查看结果；排序规则仍可继续使用。
  5. 要取消筛选，重新打开搜索，清空查询，再应用空查询。

完成之后搜索只显示匹配条目，不删除其他书。

操作提醒应用新搜索或清空搜索会重新整理列表并清除批量勾选。查询针对书名，不是全文搜索正文。

05.05按存储来源筛选书籍

操作路径书架 → 管理 → 顶部左侧来源按钮
  1. 点顶部左侧当前显示「全部来源」「TF 卡」或「内置」的按钮。
  2. 按钮在三种来源之间依次切换，列表随之更新。
  3. 查看页面上方的图书数量，确认没有把筛选后的少量书误认为全部书丢失。
  4. 恢复「全部来源」可重新显示所有符合当前搜索条件的书。

完成之后筛选来源不移动文件。

操作提醒当前固件不附带演示书，内置来源没有书籍可能是正常的。切换来源也会清除当前勾选。

05.06收藏一本书并让它排在前面

操作路径打开书籍 → 双击屏幕中间 → 题头右侧收藏标志
  1. 在书架轻点书籍封面，进入正文。
  2. 默认正文为全屏；双击屏幕中间，显示非全屏题头。
  3. 点题头右侧收藏标志，收藏当前整本书。
  4. 返回书架，检查封面左上收藏标志与排序位置。已收藏书会排在非收藏书之前。
  5. 取消收藏时，在这本书的非全屏题头再次点收藏标志。

完成之后收藏影响书架优先显示。

操作提醒封面上的收藏标记与正文书签不同：收藏针对整本书，书签针对书内某个位置。

05.07跨页选择多本书

操作路径书架 → 管理
  1. 先确定来源、排序和搜索条件，再点书籍行或右侧圆形选中标记。
  2. 点「本页全选」会选中当前管理页的书；不会自动选中整个书架。
  3. 点底部「下一页」继续选书，分页时已选项会保留。
  4. 看页面顶部「已选」本数，确认包含前面页面的选择。
  5. 点「清除勾选」可取消所有已选项；操作结束点「完成」返回书架。

完成之后同一次管理可以跨页选择。

操作提醒重新扫描、来源切换、排序切换和应用搜索会清除勾选。要做批量操作，最后再检查已选本数。

05.08只把书从书架移出

操作路径书架 → 管理 → 选择 → 移出书架
  1. 勾选需要隐藏的书，核对顶部已选本数。
  2. 点「移出书架」，阅读确认提示。
  3. 确认后，这些书从书架列表中隐藏，但 TF 卡文件和阅读记录仍保留。
  4. 以后想恢复，可到文件管理找到原书，点开阅读；重新打开会让它重新上架。

完成之后适合整理书架而保留原文件。

操作提醒不是删除。不要为了恢复它而清空卡或重新刷机。

05.09把书的阅读进度清零

操作路径书架 → 管理 → 选择 → 清进度
  1. 勾选要重新开始阅读的书，点「清进度」。
  2. 确认提示明确只清阅读进度、保留文件后，再点「确认」。
  3. 等待结果提示；如果部分项失败，按提示处理后再重试。
  4. 重新打开书籍，检查是否从起始位置开始。

完成之后原 EPUB / TXT 文件保留。

操作提醒清进度不是把书移出书架。需要保留原阅读位置时，不要选择此操作。

05.10删除卡内书籍文件

操作路径书架 → 管理 → 选择 → 删除所选
  1. 选择要删除的书，仔细核对名称和已选本数。
  2. 点「删除所选」，在二次确认中看清删除对象。
  3. 确定不再需要这些卡内文件后点「确认」。
  4. 查看成功与失败数量。没有成功的项目可检查卡是否可写，再单独处理。

完成之后成功删除的文件从存储介质移除。

操作提醒删除不可通过“重新扫描”恢复。只想隐藏书时，用「移出书架」。

05.11新书没有出现时重新扫描

操作路径书架 → 管理 → 重新扫描
  1. 先确认传输完成、设备已退出 USB 读卡或无线传输。
  2. 确认书籍在 books 或你设定的书籍目录，并保留 .epub / .txt 扩展名。
  3. 打开管理，点「重新扫描」，等待结果。
  4. 若仍不显示，清空搜索、恢复全部来源，然后在文件管理中直接查看文件是否存在。

完成之后目录变化重新反映到书架。

操作提醒扫描会清除当前勾选。目录读取异常时先处理卡状态，不要连续点击扫描。

第 06 章 / 7 项操作

文件管理：打开、改名、复制与移动

这里操作的是真实文件；书架是阅读列表。长按文件或文件夹可打开操作菜单。

06.01浏览卡根目录与下一级文件夹

操作路径文件管理 → 根目录列表
  1. 点底栏「文件管理」。上方查看存储卡状态，下方是卡根目录。
  2. 轻点文件夹名称进入目录；点左上圆形返回键回到上一级。
  3. 文件多时使用目录分页或滑动查看。目录路径能帮助确认自己现在在哪里。
  4. 在根目录找到 books、pictures、fonts 等实际文件夹，轻点进入查看。顶部三个传输按钮用于传书。

完成之后不会因为进入目录而更改文件。

操作提醒根目录的「名称 ↑」是文件列表提示，与书架管理中的“按最近”不是同一功能。

06.02从文件管理打开书籍、图片和字体

操作路径文件管理 → 文件列表 → 轻点文件
  1. 点 EPUB / TXT 文件可打开阅读，已经移出书架的书也能这样重新打开。
  2. 点 JPG / PNG 图片可进入图片查看。当前文件解码上限为 50 MiB，仍受图片尺寸与可用内存影响。
  3. 字体文件用于字体选择；将 TTF 放入字体目录后，在系统或阅读字体页应用。
  4. 任意格式文件可以存入 TF 卡，但不代表设备可以直接预览每一种格式。

完成之后根据文件类型进入对应功能。

操作提醒超过大小或解码能力时应查看错误提示；上传成功不等于格式可阅读。

06.03修改文件名称

操作路径文件管理 → 长按文件 → 重命名
  1. 长按目标文件，确认操作弹窗中的名称和路径是正确的。
  2. 点「重命名」，进入文字输入页。输入框会显示常亮光标；轻点文字或左右箭头可定位。
  3. 修改名称主体，保留原文件扩展名。某些改名页把扩展名单独显示，不必再重复输入。
  4. 中文用九宫格或全键盘拼音；数字先切「123」，英文用全键盘的「En」。
  5. 先提交候选词，再点击「确定」或页面右上「完成」，等保存成功后返回列表。

完成之后文件管理显示新名称。

操作提醒EPUB 书架书名可能来自书内元数据，文件改名不一定改变书内名称。设备内改名会迁移已保存进度；电脑上直接改名则要重新核对记录。

06.04修改文件夹名称

操作路径文件管理 → 长按文件夹 → 重命名
  1. 进入文件夹的上一级，长按目标文件夹。
  2. 点「重命名」，输入新名称并完成保存。
  3. 设备内改名会尝试同步当前书籍目录、字体目录与相关资源路径。完成后核对对应设置；必要时重新指定目录。
  4. 检查子文件仍存在，并重新扫描书架或字体列表。

完成之后文件夹路径随名称变化。

操作提醒文件夹改名不是只改一个显示标签；子文件的完整路径也会改变。

06.05复制文件或整个文件夹

操作路径文件管理 → 长按条目 → 复制
  1. 长按目标文件或文件夹，点操作面板中的「复制」。
  2. 系统在原目录生成副本，不需要另选目标位置。例如「我的书.epub」会生成「我的书 副本.epub」。
  3. 若副本名已经存在，会继续生成「副本 2」「副本 3」等名称；查看“已复制”提示确认结果。
  4. 需要把副本放到另一个目录时，再长按副本点「移动」，选择目标文件夹。

完成之后成功复制保留原文件。

操作提醒复制会占用额外空间；复制文件夹会包含其内容。复制书籍文件不等于复制原书的阅读记录。

06.06把文件移动到其他文件夹

操作路径文件管理 → 长按文件 → 移动
  1. 长按要移动的文件，在操作菜单选择「移动」。
  2. 进入「选择目标文件夹」，逐层打开目标目录。
  3. 确认屏幕路径就是目标位置，点「移动到此处」。
  4. 不想继续可点「取消移动」。成功后回原目录与目标目录分别检查。
  5. 设备内移动书籍会迁移已保存的进度；回书架重新扫描并检查。电脑或其他程序在卡上移动、改名，不一定能自动迁移本机记录。

完成之后移动成功后原位置不再保留同一文件。

操作提醒阅读中的书建议先退出，再移动它。

06.07删除单个文件或文件夹

操作路径文件管理 → 长按条目 → 删除
  1. 长按目标条目，核对弹窗中的文件名与路径。
  2. 点「删除」，进入确认提示。
  3. 点「取消」保留条目；点「确认删除」执行操作。
  4. 删除文件夹会一并删除其中的文件与子文件夹；确认前先把仍要保留的内容移出。

完成之后结果显示后再继续其他文件操作。

操作提醒重要文件先在电脑保留副本，尤其是配置备份和原书。

第 07 章 / 5 项操作

连接 WiFi、断开与遗忘

连接成功、保存过网络、正在开启传书服务，是三个不同状态。

07.01首次连接一个 WiFi

操作路径设置 → 无线连接 → WiFi → 连接或更改网络
  1. 打开设置中的 WiFi，点击「连接或更改网络」，进入无线网络列表。
  2. 查看「附近网络」，选择自己的 2.4 GHz WiFi。没有出现时点「重新扫描」。
  3. 有密码的网络会进入「连接 WiFi」输入页。用全键盘输入英文、数字和符号。
  4. 需要数字时点「123」，需要大写时点 a / A，必要时点「显示」检查密码。
  5. 点击「连接并保存」，等待结果变为已连接，并显示网络地址或可使用提示。
  6. 连接成功后返回其他页面，WiFi 可以保持连接，便于 OTA 和对时。

完成之后保存并连接该网络。

操作提醒只支持 2.4 GHz、信道 1–13。仅 5 GHz、需网页登录的公共网络等不按本文普通密码配网流程处理。

07.02检查 WiFi 密码中的大写和符号

操作路径连接 WiFi → 密码输入框
  1. 点「显示」，把掩码改为可见文字；点「隐藏」可恢复掩码。
  2. 检查大写字母、数字 0 与字母 O、数字 1 与字母 l，以及开头末尾是否多了空格。
  3. 点错误字符附近或输入框右侧箭头定位光标，删除光标前一个字符，再补入正确字符。
  4. 英文模式点左下 a / A 切换大小写；数字与符号按各自页面输入。
  5. 点「连接并保存」，以连接结果为准。

完成之后显示 / 隐藏不会主动清空已输入密码。

操作提醒WiFi 密码页不提供中文九宫格拼音输入，避免候选词干扰真实密码。

07.03连接已保存的网络

操作路径无线网络 → 当前网络 → 连接
  1. 在当前网络卡片确认保存的 SSID 是你现在要连接的网络。
  2. 若显示「已保存 · 尚未连接」，点右侧「连接」。
  3. 等待显示已连接与地址。也可使用下拉快捷面板的 WiFi 按钮发起连接。
  4. 如果周围已换网络，进入附近网络列表重新选择并保存。

完成之后不需要重新输入同一网络的密码。

操作提醒设备当前主要保留已保存的网络配置；本文不把它描述为手机那样的多网络自动漫游列表。

07.04断开网络但保留密码

操作路径无线网络 → 当前网络 → 断开
  1. 确认当前卡片显示「已连接」。
  2. 点右侧「断开」，等待提示已断开。
  3. 下一次点「连接」可用保留的密码重新连接。
  4. 快捷面板中的 WiFi 按钮也可切换连接与断开。

完成之后断开连接不等于清除密码。

操作提醒传书或 OTA 正在运行时先结束任务；断网会影响正在传输的内容。

07.05彻底遗忘已保存的网络

操作路径无线网络 → 遗忘网络
  1. 点击当前网络卡片中的「遗忘网络」。
  2. 核对确认页中的网络名称。
  3. 确认后清除本机保存的连接信息；取消则保留。
  4. 重新连接需要从附近网络列表选择并再次输入密码。

完成之后遗忘仅影响网络配置，不删除书籍。

操作提醒断开只是暂时离线，遗忘才是删除这份密码配置。

第 08 章 / 4 项操作

WiFi、热点与 USB 传输

文件管理的三个独立按钮，分别对应同网浏览器、设备热点、电脑读卡。

08.01通过家中 WiFi 传书

操作路径文件管理 → WiFi传输
  1. 让墨水屏和手机 / 电脑连接同一个无线网络。
  2. 点文件管理上方的「WiFi传输」。如果尚未配置网络，先完成 WiFi 连接。
  3. 等待传输页面显示服务状态、网址和二维码。
  4. 手机扫码，或在电脑浏览器完整输入屏幕显示的网址。使用这个本地网址，不是官网地址。
  5. 上传期间让设备停留在传输页面；等所有文件显示成功后，再返回书架。

完成之后本地浏览器可以访问 TF 卡传输页面。

操作提醒同一个网络名称也可能存在访客隔离。打不开时检查两端是否能互通，关闭手机 VPN 或访客隔离后再试。

08.02没有路由器时用热点传书

操作路径文件管理 → 热点传输
  1. 点「热点传输」，等待设备创建热点并显示连接信息。
  2. 在手机或电脑 WiFi 设置中选择屏幕上显示的热点名称，按显示的信息连接。
  3. 手机提示“没有互联网”时，选择保持连接；本次传书使用设备内的本地网页，不需要这个热点提供互联网。
  4. 热点页面可切换二维码用途：先连接热点，再打开网页网址。不要把连接热点码当作网页码。
  5. 进入传输网页上传文件，等待成功后再退出传输。

完成之后手机 / 电脑直接连接设备进行传书。

操作提醒手机若自动切回移动网络或其他 WiFi，本地地址会打不开。热点传书不等于设备已联网可做 OTA。

08.03通过 USB 把设备当读卡器

操作路径文件管理 → USB传输
  1. 使用可传数据的 USB 线连接电脑。
  2. 在设备进入「USB传输」，等屏幕显示电脑已连接。
  3. 在电脑文件管理器找到 SD_CARD 磁盘，按普通 TF 卡复制书籍、字体、图片或升级包。
  4. 等待复制结束，在电脑上执行安全弹出 SD_CARD。
  5. 回设备点「结束 USB 读卡」，然后再回书架读取。

完成之后读卡结束后设备重新使用 TF 卡。

操作提醒USB 传输时卡由电脑独占，设备无法同时读取卡内书籍。没有安全弹出就退出，可能让电脑尚未落盘的数据丢失。

08.04正确结束传书页面

操作路径设备传输页 → 返回 / 结束
  1. 先在手机 / 电脑确认上传队列没有正在进行的文件。
  2. 无线传输完成后，使用传输页面的返回 / 停止操作离开。
  3. WiFi 服务结束后，已连接的网络可继续保留，用于对时或 OTA；热点服务结束后，对应热点网页不再可用。
  4. USB 方式先在电脑安全弹出，然后才点设备上的结束读卡。
  5. 回到书架或字体列表检查新内容；必要时重新扫描。

完成之后文件服务退出，设备可正常读卡。

操作提醒不要在手机还显示上传百分比时先锁屏。

第 09 章 / 7 项操作

完成之后在选定父目录下创建子文件夹。

完成之后操作对应卡内真实文件。

09.05从手机设置状态栏个性签名

  3. 点「保存签名」，等待保存成功。
  4. 返回设备查看顶部；重启后仍保留。
  5. 要隐藏签名，清空输入框再点保存。

完成之后修改的是状态栏中间文字，不是资料卡姓名。

操作提醒不要输入换行或控制字符。太长时应缩短文字，不能仅依赖输入框字符上限。

09.06从网页上传系统或阅读字体

操作路径本地传输网页 → 上传字体

  2. 等上传成功，退出传输页面。

  4. 只上传不应用时，界面仍使用原字体。

完成之后同一个字体文件可以按需要分别选作系统或阅读字体。

操作提醒当前扫描以 .ttf 为准，别通过简单改后缀把 OTF 或压缩包伪装成 TTF。

09.07用手机图片裁剪并设置锁屏壁纸

操作路径本地传输网页 → 设置锁屏壁纸

  4. 满意后点「裁剪并设为锁屏」，等待上传与设置都成功。
  5. 结束传输，短按电源键查看壁纸锁屏。

完成之后这条操作会同时保存图片并切换为壁纸锁屏。

第 10 章 / 14 项操作

输入法：从一个字到一句话

统一键盘用于名称、签名、搜索和改名；WiFi 密码使用英文键盘。每个切换键都说明用途。

10.01认识输入框、拼音和候选栏

操作路径任意文字输入页
  1. 上方输入框显示已经确认的文字与常亮光标；光标不靠频繁闪烁来表示位置。
  2. 键盘上方的拼音区显示还没确认的拼音，下面候选栏给出可能的字或词。
  3. 点候选栏里的词，文字才会提交到输入框。
  4. 拼音未提交时直接点「确定」，系统会提示先选择词语；不会把不明拼音当作中文直接保存。
  5. 完成本次文字后，再使用键盘「确定」或当前页面的「完成 / 保存」结束编辑。

完成之后分清“正在组词”和“已输入文本”，能避免漏字。

操作提醒不同场景的最终按钮不同：WiFi 用「连接并保存」，搜索用应用搜索，名称编辑用完成。

10.02九宫格输入中文拼音

操作路径文字输入页 → 九宫格
  1. 点键盘顶部「九宫格」。九宫格只负责中文拼音，ABC / DEF 等表示字母组，不输入数字。
  2. 按拼音字母所属键依次轻点。例如「你好」的 nihao 对应 MNO → GHI → GHI → ABC → MNO。
  3. 看候选栏是否出现「你好」，点它提交。
  4. 读音不对时点九宫格左侧显示的拼音候选；更多读音点左侧「更多」。
  5. 候选词不在当前栏时，点候选栏右侧 › 向后翻，左侧 ‹ 返回。

完成之后一个词可以连续输入，不必每打一个拼音字母就选字。

操作提醒九宫格里的字母组不代表英文直输。输入英文请切到全键盘。

10.03全键盘输入中文拼音

操作路径文字输入页 → 全键盘 → 中 / En
  1. 点键盘顶部「全键盘」，查看右上模式为中文拼音。若在英文模式，点底部「En / 中」切回中文。
  2. 按字母输入完整拼音，例如 nihao 或 woxiangdushu。
  3. 查看候选「你好」或「我想读书」，点词提交。
  4. 可以继续输入下一组拼音，再次选词。句子太长时分成几段提交更容易校正。

完成之后用完整拼音获得离线字词候选。

操作提醒一次待选拼音最长 48 个输入字母；词库不是手机云输入法，未收录的长句可分段选字。

10.04输入多字词与接续联想

操作路径中文拼音模式 → 候选栏
  1. 连续输入一个词的拼音，不在中间急着选单字。先查看多字候选。
  2. 点正确词语提交。如果候选只覆盖拼音前一部分，剩余拼音会保留，继续选择后半部分。
  3. 已提交文字之后也可能出现接续字词，点需要的候选继续输入。
  4. 没有想要的词时，缩短拼音，分段或逐字选择，再继续输入。

完成之后支持离线常用词与分段组合，不必始终一个字一个字找。

操作提醒连续输入不是无限整句识别。候选选择以你看见的文本为准，确认再提交。

10.05找同音字与其他拼音读音

操作路径中文输入 → 左侧读音 / 候选左右箭头
  1. 输入拼音，查看当前候选栏。
  2. 点词栏右侧 › 继续翻候选页；不是只允许当前几个字。点 ‹ 返回前面候选。
  3. 九宫格有多种拼音解释时，点左侧读音，缩小候选范围；「更多」切换下一组读音。
  4. 找到正确字词后点它，确认已进入输入框。

完成之后同音字可跨候选页选择。

操作提醒字形缺失也可能来自选中的字体不含该字；换字前先判断是否是输入候选还是字体显示问题。

10.06从中文切换到英文输入

操作路径全键盘 → 底部中 / En
  1. 先把待选拼音提交，或用「重输」清掉待选拼音。
  2. 点顶部「全键盘」，再点底部「中 / En」。
  3. 查看模式变为「英文小写」或「英文大写」，然后输入字母。字母直接进入输入框。
  4. 要回到中文，点「En / 中」；或直接选九宫格，回到中文拼音。

完成之后全键盘可以在中文拼音与英文直输间切换。

操作提醒待选拼音没处理完时，系统会要求先选词再切换语言，避免丢掉输入。

10.07切换英文大写和小写

操作路径全键盘 → 英文模式 → 第三排左侧 a / A
  1. 点「全键盘」，确认已通过「中 / En」进入英文模式。
  2. 在字母键盘第三排最左侧找到 a / A 键，位置在 Z 左边。
  3. 点击后键面会从小写变大写；现在输入的字母就是大写。
  4. 再次点击 A / a，切回小写。切换不会修改已经输入的文字。
  5. WiFi 密码区分大小写，输入后可点「显示」核对。

完成之后按需输入 WiFi 名称、密码中的大写字母或英文名称。

操作提醒九宫格没有英文大小写功能；数字页面没有这个键，先点「ABC」回字母页。

10.08输入数字，并回到字母键盘

操作路径键盘底部 → 123 / ABC
  1. 先确认没有待选拼音；未提交时请先选词。
  2. 点左下「123」，切到数字页面。第一排为 1–0，可直接输入。
  3. 输入需要的数字，数字直接进入输入框。
  4. 点同一位置的「ABC」返回字母 / 拼音页面。

完成之后只有数字页面直接输入数字，九宫格与全键盘字母页不会把编码当数字。

操作提醒例如签名“阅读 2026”，先输入并确认“阅读”，再用空格和数字页。

10.09输入标点和特殊符号

操作路径键盘底部 → 符号 / 更多
  1. 中文拼音先选词提交，再点「符号」。
  2. 在符号页点需要的标点。中文模式显示常用中文符号，英文 / 密码模式使用 ASCII 符号。
  3. 部分符号需要点「更多」，查看另一组，例如反引号、波浪线或花括号。
  4. 完成后点「ABC」回到字母 / 拼音页。

完成之后可输入中文标点以及密码所需英文符号。

操作提醒不要用外观相似的中文全角标点替代 WiFi 密码的英文符号。

10.10插入空格或快速选第一个候选

操作路径键盘底部 → 空格 / 选择
  1. 没有待选拼音时，底部宽键显示「空格」，点它插入一个空格。
  2. 有待选拼音时，该键显示「选择」，点它提交当前页第一个候选。
  3. 如果第一候选不是你想要的，就直接点正确候选，不要按宽键。

完成之后同一个宽键随输入状态承担两个不同用途。

操作提醒WiFi 密码中的空格是真实字符；不要为了视觉分段随意加空格。

10.11把光标移到文字中间再修改

操作路径输入框 → 点文字 / 左右箭头
  1. 先点输入框里想修改的位置。常亮竖线显示插入位置。
  2. 要精确移动，用输入框里的左右箭头逐字定位。长文本会随光标显示当前片段。
  3. 新字会插入光标处；删除键删除光标前一个字符。
  4. 输入完成后检查前后文字，再保存。

完成之后可以修改中间字符，不必清空整段。

操作提醒左右箭头移动已提交文本的光标；候选栏箭头翻候选，两组箭头不同。

10.12短按删除与长按连续删除

操作路径键盘 → 退格删除
  1. 轻点 退格删除 删除一个单位：有待选拼音时先删末尾拼音，没有拼音时删光标前的文字。
  2. 按住删除约半秒开始连续删除。
  3. 持续按住可从拼音继续删到输入框文字；松手或移开到按钮外立即停止。
  4. 想从句子中间删，先把光标移到目标字符之后再操作。

完成之后连续删除不用反复点按钮。

操作提醒空文本或光标在开头时不会继续往后删。实际速度随墨水屏刷新耗时变化，不是手机级动画速度。

10.13分清「重输」和「清空」

操作路径九宫格右侧 → 重输 / 清空
  1. 九宫格「重输」清除待选拼音，保留上方已经提交的文字。拼音打错但前文正确时用它。
  2. 九宫格「清空」清除待选拼音和输入框文字。想整段重新写时使用。
  3. 数字 / 符号页的「重输」会清空整段输入；不要把它当作九宫格只清拼音的重输。
  4. 操作后先检查输入框，再继续输入。

完成之后选择对应按钮，避免误删已确认文本。

操作提醒待选拼音切换布局无法转换时，会提示先选词或重输，按提示处理后再切换。

10.14提交文字并真正保存

操作路径候选提交 → 确定 / 完成 / 连接并保存
  1. 确认候选文字已经进入上方输入框，拼音区不再有待选内容。
  2. 检查光标两边的文字、数字、符号和空格。
  3. 点击键盘「确定」，或页面的最终提交按钮；名称页用「完成」，WiFi 用「连接并保存」。
  4. 等保存成功、连接成功或返回上级后，再离开编辑。
  5. 发现提示长度上限时，缩短已输入文字；不要重复确认同一份超长文本。

完成之后保存按钮决定是否把编辑内容写入设置或文件。

操作提醒轻点键盘本身只是输入动作；没提交就离开可能丢失本次草稿。

第 11 章 / 9 项操作

打开书、翻页、目录与书签

进入正文默认全屏。工具栏、目录、收藏与书签都有明确入口。

11.01打开并退出一本书

操作路径书架 → 轻点封面
  1. 点书籍封面或列表书籍行，看到点击反馈后等待打开。
  2. 进入正文默认全屏；首次开书会读取和排版，之后按保存位置恢复。
  3. 需要查看题头返回键，双击屏幕中间区域退出全屏。
  4. 点题头左上圆形返回键退出阅读；若已配置「返回主页」按键，也可使用它。

操作提醒不要在大 EPUB 正在解析时反复强制断电；如果上次打开被中断，下次启动会先提示恢复处理。

11.02用屏幕左右半区轻点翻页

操作路径阅读设置 → 翻页模式 → 左右翻页
  1. 打开阅读工具栏，点「阅读设置 → 翻页模式」。
  2. 选「左右翻页」，点完成返回正文。
  3. 轻点屏幕左半区上一页，右半区下一页。
  4. 双击中间区域用于全屏切换，和单击翻页分开判断。

完成之后左右各占一半。

操作提醒工具栏或设置面板打开时，先完成或按已配置翻页键，避免把面板按钮当正文翻页区。

11.03用上三分之一、下三分之二轻点翻页

操作路径阅读设置 → 翻页模式 → 上下翻页
  1. 选「上下翻页」并完成。
  2. 轻点屏幕上三分之一上一页。
  3. 轻点下方三分之二下一页。中间不是一个单独的单击全屏区。
  4. 要切全屏，仍双击屏幕中间区域。

完成之后上下模式便于单手点按下半屏。

操作提醒这里是轻点区域分配，不是把横向滑动关掉。

11.04左右滑动翻页

操作路径正文 → 横向滑动
  1. 从屏幕右侧向左滑，进入下一页；从左向右滑，回上一页。
  2. 滑动要有明确横向距离，避免只轻点一下。
  3. 无论轻点模式是左右还是上下，横向滑动都可使用。
  4. 连续翻页时等当前画面完成，再开始下一次动作，避免将显示中断误认成漏翻。

完成之后滑动与轻点、按键可以一起使用。

操作提醒本项不表示上下划动一定按上下轻点模式翻页；上下模式定义的是单击区。

11.05全屏、非全屏与翻页后的自动收起

操作路径正文 → 双击中间区域
  1. 在正文中间区域快速点两次，切换全屏与非全屏。
  2. 非全屏显示题头等操作区域；全屏提供更多正文空间。
  3. 双击逻辑一直保留，不随轻点翻页模式和按键自定义变化。
  4. 非全屏时执行上一页 / 下一页，会自动回到全屏。
  5. 工具栏打开时用翻页操作，会关闭工具栏并回到全屏。

完成之后想操作界面时展开，开始翻页后恢复阅读状态。

操作提醒全屏沉浸设置控制全屏时状态栏是否隐藏；并不是关闭双击全屏功能。

11.06呼出阅读工具栏

操作路径从屏幕底部上滑 / 默认中键短按
  1. 从屏幕底部向上滑动，即可呼出阅读工具栏；默认短按中间圆圈键也可打开。
  2. 从左到右找到「目录」「书签」「阅读统计」「阅读设置」「字体设置」。当前页有书签时，书签项显示已书签。
  3. 点需要的入口打开面板；面板内有返回或完成按钮时，用它回到上一层。
  4. 即使所有按键已设成其他功能，底部上滑仍可随时打开工具栏。

完成之后工具栏集中提供书内操作。

操作提醒上滑入口不随翻页模式和按键配置改变，所有短按与中键长按都可自由设置。

11.07翻阅目录、按百分比找目录位置，再进入章节

操作路径阅读工具栏 → 目录
  1. 呼出阅读工具栏，点「目录」。章节名列表与底部目录页码一起显示。
  2. 点「‹ 上页」「下页 ›」换一页；点「« 10页」「10页 »」一次跳过十页目录。
  3. 章节很多时点「按百分比跳转」。在“跳到目录位置”面板中点按或拖动滑杆，查看“目标位置”中的目录页及章节范围。
  4. 点「跳转」回到对应的目录列表；这里还没有跳入正文。点目标章节名，才进入那一章。
  5. 不想改变目录页时点「取消」。返回正文可用目录左上圆形返回键。

完成之后百分比只帮助定位目录列表；正文位置由你随后选择的章节决定。

操作提醒目录 50% 不等于正文读到 50%，也不等于印刷书籍的中间页。目录项来自 EPUB 导航结构。

11.08添加、查看和删除书签

操作路径阅读工具栏 → 书签 / 阅读统计 → 查看书签
  1. 翻到想保存的位置，呼出工具栏，点「书签」。当前页已保存时显示「已书签」。
  2. 同一位置再次点「已书签」，即可取消这一个书签。
  3. 点「阅读统计 → 查看书签」。列表按新书签在前排列；点条目返回对应正文位置。
  4. 要删除列表中的多个条目，点右上「管理」，逐项勾选，也可点「本页全选」。
  5. 点「删除所选」，核对确认提示后确认删除。用底部分页查看其他书签；完成后点右上「完成」退出管理。

完成之后书签按正文位置保存，与整本书的收藏分开。

操作提醒当前每本书的书签数量有上限，最多 24 个。达到上限时先整理不用的条目。

11.09查看当前书的阅读统计

操作路径阅读工具栏 → 阅读统计
  1. 查看当前阅读进度、本次阅读分钟数和翻页次数。
  2. 点击「查看书签」进入当前书的书签列表。
  3. 点击「最近 30 天」查看近期阅读统计。
  4. TXT 或单章节书可以显示已排版页数；多章节 EPUB 总页数可能不固定或显示为横线。

完成之后统计反映本机记录，不是印刷页码或云端阅读时长。

操作提醒调整字体、字号、边距和图片开关会重新分页，但仍应按保存位置继续阅读。

第 12 章 / 7 项操作

阅读字体、字号、排版与首行微调

系统字体和阅读字体分开选择。排版面板的每一项影响哪里，下面逐个解释。

12.01选择自己导入的阅读字体

操作路径阅读工具栏 → 字体设置 → 阅读字体
  1. 先将可用 TTF 文件放在 fonts 或已设定的字体目录。
  2. 打开一本书，点工具栏「字体设置」，再点「阅读字体」卡片。
  3. 在字体选择页点击目标字体。长名称会截取前部显示，选中标记表示当前字体。
  4. 字体较多时翻页查看；返回正文检查字形。
  5. 这本书的题头书名和识别到的章节标题，也跟随当前阅读字体。

完成之后字体样式统一用于阅读。

操作提醒首页继续阅读书名使用系统字体；不会因这一步切换阅读字体而一起变化。

12.02把正文字号调大或调小

操作路径字体设置 → 顶部字号滑块
  1. 打开字体设置，在顶部带 A 标记的滑块查看当前数字。
  2. 向右调整增大字号，向左调整减小；松手后等待重新排版。
  3. 当前阅读字号范围为 36–72 像素。相同数字在不同字体上，视觉大小仍会不同。
  4. 回正文检查一页能容纳的行数与阅读位置，再决定是否继续调整。

完成之后字号改变正文分页，不改系统字号。

操作提醒不要用系统字号来放大正文；它主要影响首页、书架、设置等界面。

12.03调整左右边距和行距

操作路径字体设置 → 排版设置
  1. 点「排版设置」，找到上方边距与行距滑块。
  2. 边距往「小」方向调，正文可用宽度增大；往「大」方向调，两边留白变多。
  3. 行距往「紧」调，行与行更近；往「松」调，阅读行距变大。
  4. 每次只调一项，回正文检查后再继续，以便知道是哪项产生变化。

完成之后改善每行宽度与行间留白。

操作提醒边距级别会结合当前字体宽度排列，并非每一格都对应所有字体相同的字符数。

12.04调整段距和字间距

操作路径排版设置 → 段距 / 字间距
  1. 「段距」控制段落间额外留白，可选 0%、25%、50%、75% 的级别。
  2. 「字间距」从紧到松为 -4、-2、默认、+2、+4 像素。
  3. 先调段距看段落是否清晰，再调字间距避免文字过挤或过散。
  4. 点「返回字体设置」，再关闭面板查看正文。

完成之后段距与行距不是同一设置。

操作提醒字间距改变每行容字数，也会影响首行缩进的观感。换字体后可重新微调。

12.05让首行缩进准确到自己的字体

操作路径字体设置 → 排版设置 → 首行缩进 / 缩进微调
  1. 先在「首行缩进」选择「无」「1字」「2字」「3字」。常见中文段落可先选 2 字。
  2. 看「缩进微调」当前数值；点 − 减少缩进，点 + 增加缩进，每次按 1 像素微调。
  3. 可在 -20 到 +20 像素范围调整，点中间显示数值的「复位」恢复 0。
  4. 返回正文，找一个真正的段落首行，与下一行对照；不要只用章节标题或图片说明判断。
  5. 更换字体或字间距后如果仍错位，重复小幅调整。

完成之后基础字数缩进加像素微调，适应不同字形宽度。

操作提醒微调影响所有适用的正文段落，不是编辑原 EPUB 文件。选择“无”时，微调不能当成另一个段落缩进档位。

12.06给正文加虚线或点线

操作路径字体设置 → 阅读线
  1. 打开「阅读线」，选择「无」「虚线」或「点线」。
  2. 选定虚线或点线后，用「上移 2px」「下移 2px」调整位置。
  3. 偏离太多时点「恢复居中」，再做小幅调整。
  4. 点「返回字体设置」，检查阅读线与正文间的关系。

完成之后可给阅读行增加辅助线。

操作提醒选“无”时位置控制不生效。不同字体的上下留白不同，可能需要调整线的位置。

12.07开启晃动翻页并了解方向

操作路径字体设置 → 晃动翻页
  1. 在字体设置中找到「晃动翻页」开关，开启它。
  2. 横向向左晃动用于上一页，向右晃动用于下一页。
  3. 每次做一个明确动作后回稳，再开始下一次；不要持续来回抖。
  4. 触摸或其他操作期间可能被抑制，以避免同时误触。觉得影响阅读时关闭开关。

完成之后提供触摸和按键之外的翻页方式。

操作提醒灵敏度与方向取决于手持方式和动作；一次动作后有冷却与回稳要求，不是连续晃动连续翻。

第 13 章 / 6 项操作

阅读设置与刷新选项

这里设置正文操作与翻页效果，不影响四个主页的刷新模式。

13.01立即清理当前阅读画面的残影

操作路径阅读工具栏 → 阅读设置 → 手动全刷
  1. 从顶部状态栏向下滑，打开快捷面板。
  2. 点「全刷」圆形按钮，等待当前阅读画面整理完成。
  3. 也可在「阅读设置 → 按键控制」把某个短按或中键长按设为「手动全刷」。
  4. 清理后继续阅读，当前位置不改变。

完成之后主动清理文字与插图积累的残影。

操作提醒全刷可能出现明显闪动，这是清屏动作本身。它不等于换页，也不删除进度。

13.02设定每隔多少页自动全刷

操作路径阅读设置 → 自动全刷 · 阅读翻页
  1. 从 5 页、10 页、15 页、30 页、不强制中选一个。
  2. 选较小间隔更频繁整理残影；选较大间隔可减少主动全刷次数。
  3. 点「完成」回正文。残影明显时随时手动全刷，不必等待计数。

完成之后控制正文的定期全刷频率。

操作提醒「不强制」表示不按这个翻页次数定期全刷，不能保证所有页面切换、图片或异常恢复都绝不闪屏。

13.03选择默认或水波纹翻页

操作路径阅读设置 → 翻页效果
  1. 点「默认效果」或「水波纹效果」。
  2. 返回正文，用同一翻页方式比较效果。
  3. 想改主页切换效果，到系统「主页刷新模式」设置，不能用这里代替。

完成之后本项针对阅读翻页。

操作提醒图片页、跨章和需要重新排版的场景，实际刷新过程可能与纯文字页不同。

13.04把电源键短按改为下一页

操作路径阅读设置 → 电源键翻页
  1. 开启「电源键翻页」。
  2. 回正文短按电源键，翻到下一页。
  3. 需要锁屏时长按电源键；关闭该开关后，恢复通常短按锁屏的行为。
  4. 离开阅读到其他系统页面，按该页面的常规电源逻辑使用。

完成之后方便单手用电源键翻页。

操作提醒它不改变左 / 中 / 右三枚触控键的自定义。

13.05全屏时隐藏状态栏

操作路径阅读设置 → 全屏沉浸
  1. 打开「全屏沉浸」开关。
  2. 回正文，全屏时顶部状态栏隐藏；双击中间退出全屏可以再看到操作界面。
  3. 关闭后，全屏显示策略会保留相应状态栏空间。

完成之后调整全屏的沉浸程度。

操作提醒无论这个开关如何，双击中间切全屏和翻页自动收起工具栏的逻辑仍保留。

13.06关闭书内图片，但保留原文件

操作路径阅读设置 → 关闭书内图片
  1. 开启「关闭书内图片」。
  2. 等待当前书重新排版，查看插图前后是否直接衔接文字。
  3. 原 EPUB 文件不修改，之后关闭开关可恢复显示图片。
  4. 书架封面和正文插图是不同用途，关闭正文图片并不是删除卡内封面。

完成之后阅读跳过插图，避免为了不显示图片而留整块占位。

操作提醒重新分页可能改变页数和画面，但位置仍以原文记录对应；图片格式无法解码与“关闭图片”也不是同一情况。

第 14 章 / 4 项操作

按键控制：短按、长按和两套推荐

四个可配置动作是：左键短按、中键短按、右键短按、中键长按。

14.01一键应用推荐设置 1 或 2

操作路径阅读设置 → 按键控制
  1. 在按键控制面板看上方 — ○ — 示意图与当前功能。
  2. 点「推荐设置 1」：左上一页、中阅读工具栏、右下一页，中键长按手动全刷。
  3. 或点「推荐设置 2」：左返回主页、中切换全屏、右阅读工具栏，中键长按手动全刷。
  4. 核对各卡片文字已经变化，点「完成」回正文试用。

完成之后推荐设置整组应用，不需要逐个选择。

操作提醒推荐 2 的翻页主要依靠屏幕轻点、左右滑动或翻页器。

14.02自定义左、中、右键短按

操作路径按键控制 → 对应「单击」卡片
  1. 点示意图下方要改的左键、中键或右键卡片。
  2. 进入功能列表，选择上一页、下一页、阅读工具栏、切换全屏、返回主页、手动全刷或不操作。
  3. 点返回，核对卡片上显示的功能，再调整其他键。
  4. 点完成保存使用。

完成之后三枚短按键可以按习惯安排。

操作提醒“不操作”会让该键在阅读中不执行动作，确认后再使用，避免误以为设备没响应。

14.03把中键长按设成返回主页等功能

操作路径按键控制 → 中键长按
  1. 点「中键长按」这一行，进入长按功能列表。
  2. 选择「返回主页」，或选择列表中其他动作。
  3. 返回后确认中键长按显示新功能。
  4. 回正文按住中键约半秒验证；短按功能仍由上方中键单击卡片决定。

完成之后长按和短按可以承担不同功能。

操作提醒中键长按执行时不会再额外触发一次短按；别把长按的结果当成短按没设置成功。

14.04没有工具栏按键时如何打开工具栏

操作路径正文 → 从屏幕底部上滑
  1. 从屏幕底部上滑，随时呼出阅读工具栏。
  2. 三键短按和中键长按可以全部设为其他功能，不必保留工具栏按键。
  3. 底部上滑在两种翻页模式下都有效，不随按键配置改变。
  4. 重新启动和恢复配置会保留这些自定义映射，不会强制改成工具栏。

完成之后随时能够回到字体、目录和阅读设置。

操作提醒双击中间切换全屏，底部上滑呼出工具栏，两种操作互不影响。

第 15 章 / 4 项操作

蓝牙翻页器：连接、学习与书架翻页

需要支持 BLE 的翻页器；扫描会隐藏没有广播名称的设备。

15.01首次扫描与配对翻页器

操作路径设置 → 无线连接 → 蓝牙翻页器
  1. 把翻页器置于自己的配对 / 广播状态，具体按翻页器说明操作。
  2. 打开设备「蓝牙翻页器」，开启「启用蓝牙」。
  3. 点「添加翻页器 → 扫描设备」，等待出现有名称的设备。
  4. 点对应设备，等待连接完成；返回后在状态区确认显示已连接名称。
  5. 返回阅读试翻页；如果按键未映射，再使用学习操作。

完成之后已配对条目可以用于后续重新连接。

操作提醒经典蓝牙设备不等于 BLE；没有广播名称的设备被隐藏，是当前扫描策略。

15.02学习上一页和下一页按键

操作路径蓝牙翻页器 → 按键映射 → 学习
  1. 先确认翻页器显示已连接。
  2. 在「上一页」右侧点「学习」，看顶部提示，再按翻页器上想用作上一页的键。
  3. 观察设备上方「识别成功」或对应按键反馈，确认映射已经记录。
  4. 在「下一页」右侧重复学习另一枚键。
  5. 返回正文，分别按两枚键检查方向。

完成之后按键映射适配不同翻页器。

操作提醒学习时先按屏幕提示指定的一枚键；没有连接或设备没发出可识别按键事件时，不会有成功反馈。

15.03用翻页器翻书架页

操作路径蓝牙已连接 → 书架
  1. 切到书架，查看当前页码。
  2. 尝试翻页器方向键或已映射的上一页 / 下一页。支持识别到的上下方向作为书架翻页。
  3. 核对是书架分页变化，而不是打开某本书。
  4. 如果方向不符，回蓝牙按键映射重新学习，再测试。

完成之后不触屏也可切换书架页。

操作提醒不同设备的上下键可能发送不同报告；以实际识别与学习结果为准。

15.04重连、删除配对与无线互斥

操作路径蓝牙翻页器 → 已配对 / 启用蓝牙
  1. 需要重连时，在「已配对」点目标设备行。
  2. 需要遗忘翻页器时，点该行右侧「删除」；之后要重新扫描配对。
  3. 不用时关闭启用蓝牙，释放相应运行内存。

第 18 章 / 6 项操作

联网 OTA、TF 卡升级与降级

先辨认基础包能力和升级入口，再操作。官网与 Releases 的同版文件来自同一次发布。

18.01核对当前固件和升级方式

操作路径设置 → 升级和恢复 → 系统升级
  1. 查看页面上方「当前版本」，记下完整版本号。
  2. 正常使用 rc90 可选择联网 OTA 或 TF 卡应用 Bin；首次安装与修复使用网页完整包。
  3. 已有本项目双槽基础包至少 rc72 可使用相应 TF 升级；联网 OTA 从 rc79 开始提供。
  4. 更早版本或其他固件，先按官网说明完整安装兼容基础包，不要仅拿应用 Bin 尝试改变分区。

完成之后选择与当前设备基础布局相容的升级入口。

18.02联网检查更新并查看日志

操作路径连接 WiFi → 系统升级 → 检查更新
  1. 先连接可以访问互联网的 WiFi。仅连接设备传书热点不能访问更新服务器。
  2. 打开系统升级，点「检查更新」，等待服务器返回。
  3. 发现新版本后直接显示版本与「本次更新」简短日志。
  4. 想稍后再装点「稍后」；决定安装点「开始更新」。不需要先取消联网检查再启动下载。
  5. 当前已是最新版时，以页面结果为准。

完成之后在设备上可以看到新版本的简短更新说明。

操作提醒固件更新来源包含官网 kiikoread.com；页面仍显示网络错误时，可换稳定网络后重试，不必连续点击。

18.03下载并安装联网更新

操作路径发现新版本 → 开始更新
  1. 建议保持 USB 供电或确保电量充足，WiFi 信号稳定。
  2. 点开始更新，等待下载、校验、安装与重启。
  3. 下载进度不是每个数据块都刷新屏幕：黑色进度段只向前增长，较长间隔才更新百分比，减少刷新。
  4. 进度一小段时间不动不一定是卡死；观察页面状态，保持连接。
  5. 重启后进入系统升级核对版本；若校验失败按提示重试，当前可用固件槽保留。

完成之后完整校验通过后才切换到新固件。

操作提醒升级期间不要取卡、拔线或强制关机。不是等下载到 100% 就可以立即断电，还要等验证与重启。

18.04用卡根目录的 Bin 升级

操作路径官网下载 → TF 根目录 → 系统升级 → TF 卡升级
  1. 在官网选择目标版本，下载对应应用 Bin；或从同版 GitHub Release 获取应用附件。
  2. 把它准确命名为 Pico-update.bin，放到卡根目录 /，不要放 books，不要保留浏览器追加的“(1)”。
  3. 安全弹出卡或结束 USB 读卡，让设备重新读取 TF 卡。
  4. 进系统升级，在 TF 卡升级卡片中看候选版本；未读到可点「重新检查 TF 卡」。
  5. 点「安装 TF 卡升级包」，核对候选版本后点「确认升级」。
  6. 保持供电和卡连接，等安装校验与自动重启；重启后核对当前版本。

完成之后使用应用升级包写入未使用槽。

操作提醒Pico-update.bin 是兼容文件名，品牌改为 kiikoread 后也继续保留。它不是任意 Bin 都能安装。

18.05需要回到较早的正式版本

操作路径官网历史版本 / GitHub Releases → TF 卡升级
  1. 先保存配置并备份重要卡内文件，查看旧版功能差异。
  2. 选择与设备基础布局相容的原正式应用包，按 TF 根目录流程放置。
  3. 核对确认页显示的目标旧版本，再确认安装。
  4. 当前同版本安装会被拒绝；联网 OTA 只检查较新的正式版本，不用它做降级。
  5. 降级后旧版可能不认识新版设置，按需要调整；保留原配置备份以便回到新版。

完成之后兼容旧包可通过 TF 卡入口降级。

操作提醒降级不等于回退所有历史配置，旧功能也会随固件版本变化。

18.06从 Releases 给别人分享升级文件

操作路径官网 → GitHub Releases → 指定版本附件
  1. 打开项目 Releases，选择明确的正式版本标签。
  2. 需要 TF 升级时下载应用 Bin，需要电脑完整安装时下载完整 USB 包及其说明。
  3. 把文件和对应版本的操作说明一起发给对方，讲清适配设备与基础版本。
  4. 对方不用访问你的 localhost 地址；本地预览网页地址只在你自己的电脑可用。
  5. 必要时核对 SHA-256 校验值，确认转发后的文件完整。

完成之后分享的是明确版本的原发布文件。

操作提醒不要把源码 ZIP 当成可刷固件，也不要混用不同版本的引导、分区与应用文件。

第 19 章 / 4 项操作

保存配置、恢复阅读记录与 WiFi

配置文件不是整张 TF 卡镜像，恢复时应让书籍和资源保留在原路径。

19.01保存当前配置到 TF 卡

操作路径设置 → 升级和恢复 → 保存与恢复
  1. 确认卡已挂载可写，退出 USB 或传输任务。
  2. 点「保存当前配置到 TF 卡」，等待成功提示。
  3. 在根目录找到 Pico-settings.backup。
  4. 复制一份到电脑，按日期或版本另外保存，避免后续保存覆盖唯一备份。

完成之后备份设置、设备资料、阅读记录、书签与已存 WiFi 等。

操作提醒备份含 WiFi 密码，应妥善保管；锁屏密码不包含在普通配置备份中。

19.02刷机后恢复设置与阅读进度

操作路径TF 根目录放备份 → 保存与恢复 → 从 TF 卡恢复配置
  1. 把需要恢复的备份准确放在根目录，文件名为 Pico-settings.backup。
  2. 把原书籍、字体和图片也放回原目录，尤其保留书籍路径。
  3. 点「从 TF 卡恢复配置」，按提示再次点按确认恢复。
  4. 等成功后检查个人姓名、签名、WiFi、字体选择和书架。
  5. 打开原书检查阅读位置；从屏幕底部上滑可呼出工具栏，已保存的按键映射保持不变。

完成之后配置生效，记录按可用的资源路径关联。

操作提醒恢复会覆盖相应当前配置；要保留当前状态，先另存一份备份再恢复。

19.03检查备份包含什么、不包含什么

操作路径保存与恢复配置 → TF 文件备份
  1. 包含普通设置、设备资料、阅读进度与记录、书签、收藏、签名和已保存网络配置。
  2. 不包含整本书、字体文件、头像图片、壁纸图片本体；这些要另外复制。
  3. 不包含锁屏密码凭据，不会通过普通配置覆盖本机密码。
  4. 如果只想把设置分享给别人，先考虑备份里有网络密码，不要直接公开发布。

完成之后区分配置备份与资源文件备份。

操作提醒只有配置文件而没有原书，就不能恢复出一本书的正文。

19.04恢复了配置却没有进度或字体怎么办

操作路径文件管理 → 检查原路径
  1. 确认备份来自正确设备 / 时间，恢复页显示成功而不是读取失败。
  2. 查看原书完整路径与现在是否一致，确认文件大小与内容没有被替换。
  3. 确认所选 TTF、头像和壁纸仍存在；缺文件时把原资源放回或重新选择。
  4. WiFi 恢复的是连接信息，网络还需要可用；进入无线页点击连接测试。
  5. 书架仍缺项时清空搜索、切全部来源、重新扫描。

完成之后按路径与资源查错，不盲目重复恢复。

操作提醒同书不同版本 EPUB 可能大小或章节结构不同，旧位置不保证适用。

第 20 章 / 11 项操作

按现象排查常见问题

先做最小检查，再决定重新安装。保存错误提示和出问题书名，可以更快定位。

20.01书已传完，但书架没有显示

操作路径文件管理 → 管理书架
  1. 在文件管理确认文件确实存在，且不是零字节、压缩包或 ._ 附属文件。
  2. 检查扩展名为 EPUB / TXT，所在目录是 books 或已指定书籍目录。
  3. 退出 USB 读卡和无线传输后，再回书架。
  4. 清空搜索、切「全部来源」，点「重新扫描」。
  5. 曾移出书架的书在文件管理重新打开一次。

完成之后排除路径、筛选和隐藏原因。

20.02字体没有显示，或某个字变成方框

操作路径系统字体 / 阅读字体 → 字体目录
  1. 确认是真实 .ttf，文件没有复制不完整，也不是 ._ 开头文件。
  2. 检查字体目录是否正确；自定义目录需「设为字体目录」。
  3. 系统和阅读字体分别选择，确认不是只修改了另一种。
  4. 字库不含某字时，换一份包含该字的字体；输入法有候选不代表用户字体一定包含字形。
  5. 特别大的或不兼容的字体可先换较小的常规 TTF 验证。

完成之后区分字体发现、字体加载和字形缺失。

20.03插卡显示 ESP_ERR_INVALID_STATE 或读不到卡

操作路径文件管理 → 存储卡状态
  1. 先退出 USB 读卡。电脑独占卡时设备不应同时读取。
  2. 记录完整错误文字、卡容量与 FAT32 / FAT16 格式。
  3. 在电脑确认卡可正常读写；备份内容后检查分区与文件系统。
  4. 在没有文件操作时重新插卡或重启一次；不要边上传边拔卡。
  5. 仍失败可用另一张已知可用 FAT32 卡对照，并把错误、卡信息与当前版本反馈给维护者。

完成之后状态错误不自动等于硬件损坏，也不能单凭容量判断原因。

操作提醒未经备份不要直接格式化。

20.04手机能连 WiFi，却打不开传输网页

操作路径设备传输页 → 对照网址
  1. 确认设备仍停留在 WiFi / 热点传输页面，服务已开启。
  2. WiFi 模式两端同网；热点模式手机要连设备热点并保持连接。
  3. 输入屏幕显示的完整本地网址，不是 kiikoread.com；二维码用途要选网页。
  4. 检查手机是否自动切移动网络、VPN 或访客隔离。
  5. 地址变化后刷新设备二维码，用新网址重试。

完成之后连 WiFi 与本地网页可访问，是两件事。

20.05某本 EPUB 不能打开或目录跳转不对

操作路径文件管理 → 目标 EPUB
  1. 在电脑阅读器检查原书是否完整可打开。
  2. 确认传输大小正常，书籍不是 DRM 加密文件或损坏 ZIP 容器。
  3. 大文件、特殊图片格式、异常 CSS / 目录锚点都可能触发兼容限制，不能只按文件总大小判断。
  4. 如果设备给出错误，记下书名、提示和当前版本；换一份普通 EPUB 对照。
  5. 遇到“上次打开此书时中断”按启动恢复处理，先回首页再决定是否删除或重新导入。

完成之后保留可用于定位的原文件与错误。

20.06开书异常后，避免反复重启

操作路径启动 → 启动恢复提示
  1. 开书被断电或异常重启打断后，下一次启动可能显示“上次打开此书时中断”，并列出书名。
  2. 点「返回首页」先进入可操作界面。系统已经停止自动反复尝试这本书。
  3. 决定删除时点「删除这本书」，核对二次确认后再点「确认删除」。其他书与设置保留。
  4. 无卡或删除失败时先恢复卡连接，或用电脑文件管理处理；不要为了跳过提示连续强制关机。
  5. 对 EPUB 做修复或换有效版本后，再主动重新打开验证。

完成之后让你自主决定处理方式，不自动删书。

操作提醒保护针对启动记录中的确切文件；没有此书提示的所有重启，不能都归因于同一本 EPUB。

20.07残影明显、画面深浅不均怎么办

操作路径下拉快捷面板 → 全刷 / 阅读设置
  1. 先手动全刷，看是否恢复清晰；墨水屏残影不等于图片文件损坏。
  2. 正文可缩短自动全刷间隔。
  3. 主页可从快刷改普通，比较灰阶与残影；系统对比度过高可回调。
  4. 封面、点阵和波纹效果与所选主页模式有关，不要期待快刷与普通完全同样灰阶。
  5. 刷新未完成时连续切页可能影响暂时画面，等当前操作结束再继续观察。

完成之后用已有刷新选项平衡清晰与速度。

20.08打不出词、键盘切换不了或输入有延迟

操作路径输入框 → 候选 → 键盘模式
  1. 先看是否有未提交拼音。候选没选完时，切语言 / 数字符号或保存可能被阻止。
  2. 找不到长词就分段输入；同音字用候选左右箭头，多读音用九宫格左侧读音。
  3. 英文先全键盘，再 En；数字到 123；大写到字母页的 a / A。
  4. 键面短暂加深是点击反馈；停手后候选栏偶尔局部整理，是为减轻残影。
  5. 不要因为墨水屏显示较慢就连续重复按同一个保存按钮。

完成之后按具体状态排查，而不是清空整段再试。

20.09OTA 提示服务器连接失败或进度没变化

操作路径系统升级 → 联网 OTA
  1. 检查 WiFi 已连接且能访问互联网，单纯热点传书状态不够。
  2. 靠近路由器，换一个稳定的 2.4 GHz 网络，再检查更新。
  3. 下载屏幕按间隔更新进度，不是实时每秒刷新；短暂停留不一定是失败。
  4. 有明确失败提示时，结束本次任务再重试，不要强制断电。
  5. 持续连不上可用官网 Bin 的 TF 卡入口，或电脑完整刷机；使用同型号配套包。

完成之后OTA 不可用时仍有本地升级路径。

20.10TF 升级包没有被发现或拒绝安装

操作路径TF 根目录 → 系统升级
  1. 确认文件名准确为 Pico-update.bin，没有 (1)、双重 .bin 或多一层目录。
  2. 确认是应用升级包，不是完整 USB ZIP、源码 ZIP 或引导 Bin。
  3. 确认卡挂载正常，结束 USB 读卡，再点重新检查 TF 卡。
  4. 同版拒绝是现有规则；需要本地同版本测试时用对应网页安装方式，不伪造版本号。
  5. 项目名、布局、尺寸或镜像校验不通过时，重新下载适配原包，不要强行安装。

完成之后以设备候选版本与检查结果为准。

20.11网页安装失败或串口列表没有设备

操作路径官网安装器 → 电脑 USB
  1. 换一根已知可传数据的 USB 线，换电脑接口，再观察串口列表。
  2. 关闭其他刷机标签和串口工具，重新连接当前网页。
  3. 使用电脑 Chrome / Edge，通过 HTTPS 打开官网。
  4. 正常系统可进入「设置 → 升级和恢复 → BOOT 刷机」再重试。
  5. 设备无法进入系统时，按具体硬件官方恢复方法处理或联系维护者；本文不提供不存在的实体 BOOT 键操作。

完成之后先解决下载连接，再安装固件。
