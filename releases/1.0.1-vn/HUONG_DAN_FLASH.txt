# Hướng dẫn nạp firmware dpReader 1.0.1-vn cho Metalio E-ink 4 Plus

## Phương pháp 1: Nạp qua USB (đầy đủ)

Sử dụng file: dpReader-metalio47-1.0.1-vn-full.bin

1. Cài đặt esptool.py:
   pip install esptool

2. Kết nối thiết bị qua USB và kiểm tra cổng:
   - macOS/Linux: /dev/ttyUSB0 hoặc /dev/cu.usbserial-*
   - Windows: COM3 hoặc COM4

3. Nạp firmware:
   esptool.py -p /dev/ttyUSB0 -b 921600 write_flash 0x0 dpReader-metalio47-1.0.1-vn-full.bin

## Phương pháp 2: Nạp qua thẻ TF/microSD (chỉ cập nhật ứng dụng)

Sử dụng file: dpReader-metalio47-1.0.1-vn.bin

1. Sao chép file dpReader-metalio47-1.0.1-vn.bin vào thư mục gốc của thẻ TF
2. Đổi tên file phù hợp với hệ điều hành hiện tại trên máy:
   - Từ ROM gốc nhà sản xuất (CloudZao): đổi tên thành Metalio-E-Ink4-Plus.bin (khởi động lại máy sẽ tự báo nâng cấp).
   - Từ Kiikoread: đổi tên thành Metalio-S31-update.bin (vào Cài đặt -> Cập nhật hệ thống -> Nâng cấp thẻ TF).
   - Nếu máy đã chạy dpReader: giữ nguyên tên, mở "Tệp" (Quản lý tệp) -> chạm 2 lần vào file .bin để cập nhật.
3. Lắp thẻ TF vào thiết bị và thực hiện nâng cấp.

QUAN TRỌNG:
- Đảm bảo VCOM của thiết bị đã được hiệu chỉnh đúng (mặc định 1200 mV)
- Không sử dụng file USB full để cập nhật qua TF
- Kiểm tra checksum SHA256 trước khi nạp (xem SHA256SUMS.txt)
