# 独立 S31 硬件约束

- Metalio E-INK4 Plus V1.5 / E0470A14-AF 34Pin；物理1216×684，竖屏界面684×1216。
- ESP32-S31，Flash16MB DIO80，Octal PSRAM200，CPU320MHz；使用匹配的 S31 SDK。
- LCD8bit/20MHz、192行预填、12ms最短相位；原始GC48/GL48/DU20数组保持。默认完整48相，裁剪关闭；裁剪仅为可选官方运行派生，不复制Pico37相表或16bit打包。
- TPS65185、TCA9555；XOE18/MOD19直连。PWRUP与VCOM_CTRL同一共享端口原子置高；GPIO PG→ENABLE→运行VCOM→寄存器PG；整轮呈现后立即断高压，XOE先低至少12us。
- VCOM默认3000mV来自Moku对比机结果，不代表本机实测；900～4000mV、10mV步进、已有NVS值优先。成功写入并回读才确认保存；只写运行寄存器，不烧永久OTP。断电时显示最近成功的寄存器回读，并非实测电压。
- GPIO36高=下载/SerialJTAG33/34，低=UTMI专用USB pad44/45。后者是芯片管脚编号，不能按GPIO44/45配置。保留正常USJ、MSC切换和返回下载路径。
- SDMMC slot0四线：CLK24/CMD25/D0-D3=20-23。前光GPIO6/7；GPIO2是共享中断，不可作为蜂鸣器输出。
- FT6336U坐标、盖板键和原厂IRQ采样保留，不给未确认的触摸模组烧写控制器固件。
- 前光2×2开关与亮度/冷暖竖滑块保留；灯泡/太阳/对比度图标，关灯时调整滑块不自动开灯。震动、电池/充电、PCF8563 RTC均保留。
- 独立分区、设置命名空间、字体加载事务、异常启动字体保护、PIN与锁屏前关灯保留。
- 默认锁屏保留待机；可选浅睡/深睡受USB、拿起、PIN、存储和资源所有权保护。没有实测功耗承诺。防淡墨按完整空闲间隔运行，不创建锁屏定时唤醒任务。

完整0x0镜像只用于同板型初装；已有固件的应用更新按实际OTA槽处理，不能固定写入初装偏移。
