# 独立 S31 硬件约束

- V1.5、E0470A14-AF 34Pin；物理1216×684，竖屏界面684×1216。
- Flash16MB DIO80、Octal PSRAM200；只使用ESP32-S31 SDK。
- LCD8bit/20MHz、192行预填、12ms最短相位；默认使用Metalio原GC48/GL48/DU20完整表（对齐厂家2.0.76：裁剪会把黑目标饱和期从18帧减到13帧，强光下偏淡且灰阶非单调），`E0470_WAVEFORM_TRIM=1` 才回退官方GC36/GL37裁剪。完整表/派生表都保留"白→白"擦白补帧并在尾段再补几帧擦白：全像素页刷会重新驱动白底，否则白底只靠电荷保持，强光下几秒内变灰。Pico的37相原波形及16bit总线不可复制过来。
- TPS65185、TCA9555；XOE18/MOD19直连GPIO。上电顺序与每帧断电对齐厂家2.0.76的`epd_refresh.cc`+`epd_board_poweron`：PWRUP和VCOM_CTRL同时拉高、等PWR_GOOD、ENABLE=0x3F后写VCOM、PG=0xFA后才放开输出；每帧推完立刻`epd_poweroff()`，不保留高压轨（带电但驱动已释放的像素在强光下会灌灰，这是"页刷后白底变灰"的根因）。VCOM 实测最优 **3000mV（-3.00V，与对比机黑度一致；厂家config默认1200，可在调试面板A/B）**，900–4000mV、10mV一档可调，值存NVS，只写运行寄存器，不烧TPS永久OTP。
- GPIO36模拟开关：高电平保留原生下载/SerialJTAG路径，低电平进入OTG路径。USB读卡与下载口切换按本机驱动，不复制S3共用PHY处理。
- SDMMC slot0四线：CLK24/CMD25/D0-D3=20-23。前光GPIO6/7；GPIO2为共享中断，不可作为蜂鸣器输出。
- FT6336U坐标/盖板键、震动、电池/充电、PCF8563 RTC、S31独立睡眠与恢复逻辑均保留。
- 默认锁屏保留待机；可选浅睡/深睡受USB、拿起、PIN、存储及资源所有权保护。当前没有实测功耗承诺。

完整Bin只用于同板型初装，不能拿Pico或原厂不同分区的应用偏移直接刷。
